Objects on the table — measured vs. true
This is a real camera, so there is no ground truth to compare against — the confidence column is the detector's own score, not a measure of size accuracy. Sizes are only trustworthy if the calibration badge above is green; a stale calibration produces confident, wrong numbers.
True sizes are known because the scene is simulated — that is what makes the error column meaningful. It reports the worst of the three dimensions, with the offending one in brackets (L, W or H); hover for all three. A height marked guessed could not be measured from this camera angle, so a typical value for that object type is shown instead. Those heights are left OUT of the error column, because the gap would measure the assumption rather than the vision.
